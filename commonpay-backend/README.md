# CommonPay Backend

Python, FastAPI and PostgreSQL-based modular financial platform.

Core domains:
- Identity and access management
- Financial accounts and ledger
- Payment orchestration
- Flutterwave and Paystack adapters
- FX and treasury
- Developer API infrastructure
- AI intelligence and authorised tools
- Compliance, audit and reconciliation

Financial invariants and regulatory controls must be established before live financial operations.
