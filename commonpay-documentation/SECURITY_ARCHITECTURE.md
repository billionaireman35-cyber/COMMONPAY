# Security Architecture

Required controls:
- Strong authentication and MFA.
- Session and device management.
- Role-based and resource-level permissions.
- Secrets management.
- Encryption in transit and at rest.
- API rate limiting.
- Transaction-specific authorisation.
- Webhook signature verification.
- Idempotency.
- Tamper-resistant audit events.
- Security monitoring.
- Backup and disaster recovery.
- Dependency and vulnerability management.

The initial API key implementation is a development boundary, not a
complete production identity or merchant access system.
